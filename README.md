# 한글 따라쓰기 (유아용 안드로이드 앱)

- 그림 + 단어가 무작위로 나오고, 글자 칸마다 연한 글자를 손가락으로 따라 씁니다.
- 한 글자를 다 쓰면 "띵동", 단어를 다 쓰면 팡파레 + 폭죽 + 색종이, 그리고 **다음 단어** 버튼이 나옵니다.
- 그림이나 단어를 누르면 단어를 읽어줍니다 (폰의 한국어 음성 엔진 사용).
- 외부 라이브러리·효과음 파일 없이 순수 안드로이드 API로 만들었습니다.

## APK 받는 법 (GitHub Actions)
1. 이 폴더를 GitHub 저장소에 올립니다 (`main` 브랜치).
2. 저장소의 **Actions** 탭에서 "Build APK"가 끝나길 기다립니다 (3~5분).
3. 저장소 오른쪽의 **Releases → 최신 APK**에서 `hangul-tracing.apk`를 폰으로 내려받아 설치합니다.
   (처음엔 "출처를 알 수 없는 앱 설치"를 허용해야 해요.)
